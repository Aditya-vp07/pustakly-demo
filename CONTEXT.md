# Pustakly — project context for review
_Generated by Fo on 17 Oct 2026, ~01:10 IST. Hand this to any agent or collaborator to bring them up to speed._

## What this project is
Aditya is building **Pustakly** (working brand name, not locked): a small-guides ebook store for Indian students and early-career readers. One niche goes live first (AI Tools for Students, Hindi), priced in the impulse band (entry ₹19, core ₹49, bundle ₹99), sold through Instagram reels traffic. This repo holds the website.

## Where things stand
- **Live demo:** https://aditya-vp07.github.io/pustakly-demo/ (GitHub Pages, public repo, branch `master`)
- **Stack:** static HTML + CSS + vanilla JS. No frameworks, no build step. Deployable as-is to Cloudflare Pages (Aditya's planned production host; Vercel is out because it blocks commercial use on free plans).
- **Structure:**
  - `index.html` — landing page: hero, 3-question book-finder quiz, featured guide, marquee strip, all-guides grid (1 live, 5 "coming"), trust section, sticky mobile buy bar
  - `guide-ai-tools.html` — product page: tap-to-flip sample-chapter preview, what's-inside list, "this is for you / NOT for you" blocks, sticky price panel, buy button (placeholder)
  - `css/style.css` — the whole design system
  - `js/main.js` — all interactions
  - `assets/favicon.svg`

## Design system (deliberate anti-AI-slop choices)
- **Colors:** warm near-black `#151210`, cream paper `#f7f1e6`, ONE accent amber `#f5a524`. No gradients as decoration, no purple/blue.
- **Type:** Bricolage Grotesque (display, Google Fonts) + system stack for body (speed). Hindi face planned: Noto Serif Devanagari.
- **Rhythm:** sections alternate dark/cream deliberately; spacing is uneven on purpose.
- **Motion (all CSS/JS, <15 KB, `prefers-reduced-motion` respected):** word-by-word kinetic hero, staggered scroll-reveal via IntersectionObserver, count-up stats, price-strike that draws itself, button press feedback, sticky mobile buy bar after the hero, marquee strip (pauses on hover), 3D flip sample-chapter preview, spring-in quiz match card.
- **Honesty rules:** no fake timers, no invented income claims, no fake counters (fake urgency is illegal under India's CCPA 2023 dark-pattern rules). Refund line: "Digital download, no refunds once delivered. Any issue, message us and we'll sort it."

## Business context (why the site looks like this)
Competitor research found: reseller accounts selling "earn ₹30k/month" ebooks with tiny followings (trust gap), and one professional funnel (lp.sonnetskills.com) doing ₹9 + GST entry → ₹99 bundle → ₹499/year membership with full policy pages. Pustakly's wedge: real author, honest offers, shown-before-you-buy sample, regional languages later. Different accounts per region/language after first 20–30 sales.
